# Pawchive APK

A small, unofficial Android client for [Pawchive](https://pawchive.pw/), built with Kotlin and Jetpack Compose.

This is a rough personal project with limited testing. Many things still need work, so please keep your expectations modest. It is not affiliated with the website.

To build, install JDK 17 and Android SDK 37, set your SDK path in `android/local.properties`, then run:

```sh
cd android
./gradlew assembleDebug
```

Android 8.0 or newer is required.
